# موقع طلبات شركة ETI

موقع يعرض أصناف الشركة للعميل (صاحب المحل)، يختار منها **كرتون / باكيت / حبة**،
ثم تُرسل الفاتورة كاملة إلى **واتساب الشركة**.

## الأقسام

| الصفحة | الرابط | الوظيفة |
| --- | --- | --- |
| الأصناف | `/` | كل الأصناف المتوفرة مع الصورة والشرح والأسعار وأزرار الإضافة |
| السلة والفاتورة | `/cart` | تعديل الكميات + بيانات العميل + إرسال الفاتورة واتساب |
| طلباتي | `/orders` | الطلبات السابقة المحفوظة على الجهاز |
| الإدارة | `/admin` | رفع ملف Excel + إرفاق الصور + تعديل الكميات والإعدادات |

كلمة مرور الإدارة الافتراضية: `eti2026` — **وتُغيَّر من داخل لوحة الإدارة نفسها**
(قسم «تغيير كلمة مرور لوحة الإدارة») وتُحفظ مشفّرة في قاعدة البيانات، ولا تُغيَّر من الملفات إلا
عند إعادة النشر من الصفر (`ADMIN_PASSWORD` في `.env`).

## كل كارت صنف في التطبيق يعرض

- الصورة + اسم المادة + الصنف (التصنيف) + الشرح.
- **الكرتون**: سعره + كم باكيت فيه (وكم حبة).
- **الباكيت**: سعره + كم حبة فيه.
- **الحبة**: سعرها.
- سعر بيع الحبة في المحل + **ربح العميل** للكرتون/الباكيت/الحبة.
- أزرار: `+ كرتون` و `+ باكيت` و `+ حبة`.

## الفاتورة المرسلة عبر واتساب تتضمن

اسم المادة، الصنف، الكمية (وبداخلها عدد الحبات)، سعر الوحدة، إجمالي السطر،
**ربح العميل** لكل سطر، ثم إجمالي الفاتورة وإجمالي البيع المتوقع بالمحل وربح العميل الكلي.

## ملف Excel المتوقع

يُرفع من `/admin` ويتم فهم الأعمدة تلقائياً (عربي أو إنجليزي، مع تجاهل التشكيل):
`الكود`، `المادة`، `الصنف`، `الشرح`، `باكيت بالكرتون`، `حبة بالباكيت`،
`سعر الكرتون`، `سعر الباكيت`، `سعر الحبة`، `سعر بيع الحبة بالمحل`.

- **لا تضع عمود الكمية في الإكسل.** المخزون يُعدَّل من لوحة الإدارة (خانة الكمية الخضراء).
- الصنف الجديد من الإكسل يبدأ بكمية 0 (مخفي) حتى تكتب كميته من الإدارة.
- رفع الإكسل لا يمسح الكميات السابقة ولا الصور.
- يمكن تحميل **قالب جاهز** من صفحة الإدارة (زر «تحميل قالب Excel»).
- عند الرفع اختر معنى عمود «سعر الحبة»: سعر بيع المحل أم سعر الشراء من ETI.
- وضع «تحديث كامل» يخفي الأصناف غير الموجودة في الملف، ووضع «دمج فقط» يحدّث ما في الملف فقط.
- **أي صنف كميته 0 لا يظهر للعميل نهائياً.**
- القيم الناقصة تُستنتج تلقائياً (سعر الباكيت من سعر الكرتون ÷ عدد الباكيت … إلخ).

## إعدادات واتساب

من `/admin` → «إعدادات الفاتورة وواتساب»: رقم الشركة بصيغة دولية بدون `+` (مثال: `201000000000`)،
العملة، اسم الشركة، والملاحظة التي تظهر أسفل الفاتورة.

## التقنيات

Next.js (App Router) + PostgreSQL عبر Drizzle ORM + Tailwind CSS + SheetJS لقراءة Excel.
